# Telegram Bot для транскрибации голосовых сообщений

Бот для автоматической транскрибации голосовых сообщений из Telegram и отправки текста на сайт как заметки.

## Возможности

- 🎤 Транскрибация голосовых сообщений Telegram
- 🎵 Обработка аудио файлов
- 📝 Автоматическая отправка транскрибаций на сайт как заметки
- 🔄 Резервное локальное сохранение при ошибках
- 🚀 **Предзагрузка модели Whisper** при старте (не ждёт загрузку при каждом сообщении)
- 🔇 **VAD-фильтр** (вырезание тишины через WebRTC VAD) — более чистый текст
- ⏱ **Проверка длительности** аудио перед транскрибацией
- 🎮 **Транскрибация на GPU** (NVIDIA CUDA / Apple Metal) с fp16 для ускорения
- 🏠 Использует локальную модель Whisper — бесплатно и конфиденциально
- 🎯 Поддержка русского языка

## Требования

- Python 3.8+
- Telegram Bot Token (от @BotFather)
- FFmpeg (для работы с аудио)
- Видеокарта NVIDIA (CUDA) или Apple Silicon (MPS) для ускорения (опционально)

## Установка

### 1. Клонирование и настройка окружения

```bash
cd telegram-bot
python -m venv venv
# Windows:
venv\Scripts\activate
# Linux/Mac:
source venv/bin/activate
```

### 2. Установка зависимостей

```bash
pip install -r requirements.txt

# Установите FFmpeg (обязательно для работы с аудио)
# Windows: скачайте с https://ffmpeg.org/download.html и добавьте в PATH
# Ubuntu/Debian: sudo apt update && sudo apt install ffmpeg
# macOS: brew install ffmpeg
```

### 3. Настройка конфигурации

```bash
cp .env.example .env
# Отредактируйте .env и вставьте свои токены
```

### 4. Запуск

```bash
python bot.py
```

При первом запуске модель Whisper автоматически загрузится (10-30 секунд) и останется в памяти.

## Конфигурация (.env)

| Переменная | Описание | По умолчанию |
|---|---|---|
| `TELEGRAM_BOT_TOKEN` | Токен от @BotFather | — |
| `API_URL` | URL сайта для отправки заметок | `http://localhost:3000/api` |
| `API_KEY` | Ключ авторизации API (если нужен) | — |
| `WHISPER_MODEL_SIZE` | Размер модели: tiny, base, small, medium, large | `base` |
| `OPENROUTER_API_KEY` | Ключ для анализа заметок ИИ | — |
| `ADMIN_USER_ID` | Telegram ID для уведомлений о запуске | — |
| `MAX_AUDIO_DURATION_SECONDS` | Максимальная длина аудио в секундах | `600` (10 мин) |

## Как это работает

1. Пользователь отправляет голосовое сообщение или аудиофайл
2. Бот проверяет длительность — если > `MAX_AUDIO_DURATION`, сообщение отклоняется
3. Аудио конвертируется в WAV (16kHz, mono, 16-bit)
4. **VAD-фильтр** вырезает тишину — остаётся только речь
5. Whisper транскрибирует на GPU (если есть) или CPU
6. OpenRouter анализирует текст — выделяет тему и главную мысль
7. Результат отправляется пользователю и на сайт (API)

## Ускорение на видеокарте

Бот автоматически определяет доступное устройство:
- **NVIDIA GPU** — использует CUDA + fp16
- **Apple Silicon** (M1/M2/M3) — использует MPS + fp16
- **CPU** — если GPU не найден
